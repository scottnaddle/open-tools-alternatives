# 상태 기록

기능 PR은 `STATUS.md`의 `마지막 갱신` 줄과 공유 절을 고치지 않는다. 이 디렉터리에 파일 하나만 새로 만든다.

파일 이름: `YYYY-MM-DD-<slug>.md`. 다른 PR이 만든 파일은 수정하지 않는다.

```
머리글: 2026-10-15 — 한 줄 요약
```

`머리글:` 은 한 줄이다. 병합 뒤에 `python3 scripts/refresh_status_header.py` 가 그 줄을 `STATUS.md`의 `마지막 갱신`에 넣는다. 그 스크립트는 다른 줄을 바꾸지 않는다. 기능 PR에서 실행하지 않는다.
