이미 있는 웹 페이지를 찍어, 가로 소개 영상으로 만들어 주는 스킬입니다. 교실을 찍는 앱이 아닙니다. 교사가 Claude Code나 Codex에게 페이지를 맡기면, 코드로 그린 영상 파일(MP4)이 나옵니다.

수업 준비에 어떻게 쓰나

저장소가 말하는 용도는 제품 홍보 영상입니다. 교사는 같은 순서로, 이미 공개한 페이지만 넣을 수 있습니다.

  • 학급 홈, 행사 안내, 과제 안내처럼 주소가 있는 페이지를 보여 주고, 소개 영상을 맡깁니다.
  • 샷 이름은 갤러리에서 복사해 그대로 말할 수 있습니다. README 예시는 deck-deal-flyin, spotlight-hero-card입니다.
  • 빠르게 가려면 Ink Press 템플릿에 스크린샷, 문구, 로고를 넣는 길입니다.
  • 파일은 MP4, 가로 1920×1080, 30fps, h264이고 음악과 효과음이 들어갑니다. Remotion 프로젝트 원본도 남습니다.

학생 얼굴 영상이나 수행평가 촬영본을 잘라 주는 기능은 이 저장소 안내에 없습니다.

준비부터 파일까지

  1. Claude Code 또는 Codex가 필요합니다. README는 이 스킬을 그 둘에 맞춰 만들었다고 합니다.
  2. 에이전트에게 이 문장을 보냅니다. Install this skill for me: https://github.com/Vincentwei1021/video-shotcraft
  3. 터미널을 쓴다면 npx skills add Vincentwei1021/video-shotcraft 입니다. 저장소를 직접 받으면 Claude는 ~/.claude/skills/video-shotcraft, Codex는 ~/.codex/skills/video-shotcraft로 연결합니다.
  4. Node.js, npm, ffmpeg, ffprobe가 있어야 합니다. uv는 배경음악 박자를 볼 때만, puppeteer는 페이지를 찍을 때 스크립트가 설치합니다. Remotion은 처음 렌더할 때 헤드리스 크롬을 받습니다.
  5. 그다음 말합니다. Use video-shotcraft to make a promo for my product. 페이지 주소나 프로젝트 폴더를 함께 줍니다.
  6. 영상이 나오면 브라우저 편집기가 열립니다. 다시 열려면 node workbench/scripts/open.mjs 뒤에 프로젝트 이름을 붙입니다.

시험한 환경은 macOS입니다. Linux는 동시 작업 수, 크롬 실행 파일, CDN이 막힐 때를 README가 따로 적습니다. Windows에서 렌더가 되는지는 적혀 있지 않습니다.

학생 정보. 실제 페이지는 스크린샷으로 넣습니다. 공개된 데모 화면만, 확인한 뒤에 남기라고 합니다. 개인·고객·내부 자료, 열쇠, 실시간 데이터는 가짜로 바꾸거나 가리고, 찍기 전에 멈춰 두라고 SKILL.md에 있습니다. 학급 페이지의 이름, 사진, 점수는 지우십시오. 학생에게 이 도구를 직접 쓰라는 안내는 없습니다. 그래서 용도 구분은 교사 개인용입니다.
계정과 키. 영상을 만드는 준비물 표에는 API 키가 없습니다. Claude Code와 Codex 가입 방법은 이 저장소에 없습니다. 소셜에 올릴 때만, 사용자가 요청하면 Upload-Post 키와 프로필 이름이 필요합니다. 무료는 한 달에 10번이고 TikTok은 유료입니다. 문구와 올릴 곳을 확인한 뒤에 보냅니다.
라이선스. 코드와 문서는 Apache-2.0, 저작권 2026 Wei Yihao 입니다. 소리 파일은 여기에 포함되지 않았고, 라이선스도 따로입니다. 대부분은 Mixkit이고, 일부는 출처를 되찾지 못해 상업 사용 전에 확인하라고 ATTRIBUTION.md에 있습니다. Remotion은 개인과 작은 팀은 무료이고 회사는 유료일 수 있다고 README가 안내합니다. 학교가 어디에 해당하는지는 적혀 있지 않습니다. Remotion 라이선스를 따로 보십시오. 젠잉(캡컷 중국판)으로 보내는 기능은 macOS의 JianYing Pro 11.2에서 확인했고, Windows 설치기는 시험하지 않았다고 합니다.

안내 글은 영어와 중국어입니다. 한국어 안내는 없습니다. 저장소 한 줄 소개는 아직 샷 레시피 152개, 모션 미리보기 209개라고 적혀 있습니다. 2026-10 본문은 카드 124장, 샷 150개입니다. 이 페이지는 본문을 따릅니다.
